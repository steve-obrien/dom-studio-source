## Spinner styles and sizes

Set `variant="tail"` to fade the rotating highlight into the ring. The default `arc` variant uses a solid highlight. Both variants support `sm`, `md`, and `lg` sizes and respect reduced-motion preferences.

<!-- example: SpinnerVariants -->

## Loading on a dark surface

`foreground` sets the highlight and `background` sets the ring track. Leave `background` unset to use a faint tint of the highlight. Use `label` to describe what is loading when the spinner provides the status on its own.
